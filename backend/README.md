### Ejecución con Maven

Para iniciar el backend de **ChurnCheck**, utiliza los siguientes comandos:
* **Compilar el proyecto:** `mvn clean install`
* **Ejecutar:** `mvn spring-boot:run`
* **Ejecutar con un perfil específico:** `mvn spring-boot:run -Dspring-boot.run.profiles=nombre-perfil`
